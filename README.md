# NotedMaybe 📝

> “Porque lembrar de tudo sozinho é demasiado otimista.”

NotedMaybe é uma app moderna de notas, organização e produtividade criada para simplificar o dia a dia.  
Uma mistura entre notas rápidas, to-do list, agenda e “brain dump” — tudo num só lugar.

## ✨ Features

- ✅ Criar notas rapidamente
- 📌 Organizar tarefas importantes
- 📱 Interface moderna e responsiva
- ☁️ Backend com Supabase
- ⚡ Experiência rápida e simples

## 🚀 Tecnologias Utilizadas

- React
- Vite
- Supabase
- Vercel

## 📸 Preview

Website:  
👉 https://notedmaybe.vercel.app/

## 🎯 Objetivo

O objetivo do NotedMaybe é ajudar utilizadores a organizarem a vida sem complicações.

Nem sempre precisamos de apps ultra complexas.  
Às vezes só precisamos de um sítio onde escrever:

- ideias
- tarefas
- lembretes
- coisas aleatórias às 3 da manhã

## 🛠️ Instalação Local

Clone o projeto:

```bash
git clone https://github.com/pedro84leal-cpu/notedMaybe.git
```

Entrar na pasta:

```bash
cd notedmaybe
```

Instalar dependências:

```bash
npm install
```

Iniciar projeto:

```bash
npm run dev
```

## 🌐 Deploy

O projeto está alojado na Vercel.
